# 📦 Supply Chain Performance Analytics

## 📌 Project Overview

This project analyzes a global supply chain dataset containing over **180,000+ order records** to uncover insights into sales performance, profitability, customer behavior, delivery efficiency, and shipping operations.

The analysis was performed using **Python**, **MySQL**, and **Power BI**, following a complete data analytics workflow from data cleaning to interactive dashboard creation and business recommendations.

---

## 🎯 Project Objectives

- Analyze sales and profit performance across regions and product categories.
- Identify top-performing products and customers.
- Evaluate shipping modes and delivery performance.
- Monitor late delivery risks.
- Analyze monthly sales trends.
- Generate business insights to improve operational efficiency.

## 📂 Project Workflow

### 1️⃣ Data Collection
- Imported Supply Chain dataset
- Verified dataset structure and data types

### 2️⃣ Data Cleaning (Python)
- Checked missing values
- Removed duplicate records

- Performed Exploratory Data Analysis (EDA)

### 3️⃣ SQL Analysis
Performed business analysis using MySQL, including:
- Total Sales & Profit
- Top Regions by Sales
- Top Categories by Sales
- Top Products by Sales
- Customer Revenue Analysis
- Delivery Status Analysis
- Shipping Mode Performance
- Late Delivery Risk
- Profitability Analysis
- Monthly Sales Trend

### 4️⃣ Power BI Dashboard
Designed an interactive dashboard consisting of:
- Executive Overview
- Sales Performance Analysis
- Delivery & Logistics Analysis
- Product & Profit Analysis

## 📈 Business Insights

- Western Europe and Central America generated the highest revenue.
- Standard Class contributed the highest sales volume.
- Late deliveries accounted for a significant share of total shipments.
- A small number of products generated a large portion of overall revenue.
- Profitability varied across product categories, highlighting optimization opportunities.
- Monthly sales remained relatively stable with seasonal fluctuations.

---

## 💡 Business Recommendations

- Improve logistics planning to reduce late deliveries.
- Prioritize inventory for top-performing products.
- Optimize shipping methods based on delivery performance.
- Review discount strategies to improve profitability.
- Focus marketing efforts on high-revenue regions.
